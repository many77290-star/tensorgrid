TensorGrid API

Market intelligence, as JSON.

One endpoint per need. Refreshed every 15 minutes by an automated pipeline. No SDK, no auth on the public tier, stable field names.

Base URL

BASEhttps://many77290-star.github.io/tensorgrid/feeds

All endpoints are GET. All responses are UTF-8 JSON. All timestamps are ISO-8601 UTC.

Endpoints

1. Subnets — the full normalized universe

GET/feeds/subnets.json

Every Bittensor subnet alpha token with its price, market cap, volume, 24h/7d/30d performance, ranks, and the alpha-vs-TAO signal.

2. Meta — feed envelope

GET/feeds/meta.json

Version, API base, refresh cadence, rate limits, contact. Use it to detect breaking changes.

3. Historical — daily snapshots

GET/feeds/history/snapshot-YYYYMMDD.json

One light snapshot per day: TAO price, universe median 30d, beat-TAO count, top-5 market caps. Retention: 400 days (rolling).

Field reference

tao:              { usd, var24h, var7d, var30d, market_cap_usd, total_volume_usd }
universe:         { count, with_30d_data, median_30d, beat_tao_count, beat_tao_pct }
subnets[]: {
  symbol             string   lowercase CoinGecko symbol (sn4, sn51, ...)
  name               string   CoinGecko name (can be null)
  id                 string   CoinGecko id (stable)
  usd                number   current price, USD
  var24h, var7d, var30d  number
  var30d_glitched   boolean    true if |var30d| > 3000 (neutralized, null in var30d)
  market_cap_usd     number|null
  total_volume_usd   number|null
  circulating_supply number|null
  ath_usd            number|null   all-time high
  high_24h, low_24h  number|null   24h range
  rank_by_mcap       int          1 = largest market cap
  rank_by_30d        int|null     1 = biggest 30d performer (glitch-filtered)
  beats_tao_30d      boolean      var30d > tao.var30d AND both present
}

Data hygiene

  • Upstream: CoinGecko public market data, category bittensor-subnets.
  • 30d glitch filter: any 30d change beyond ±3,000 % is nullified in var30d and flagged via var30d_glitched: true. Ranks and the beat-TAO counter ignore glitched tokens.
  • Missing fields: when upstream doesn't report a value, the field is null — never a sentinel 0.
  • Ranks: computed at refresh time from the current snapshot; they are not time-series-stable.
  • Refresh: every 15 minutes (cron on the hosting machine). Client-side terminals refresh every 5 minutes with Cache: no-store.

Rate limits & fair use

  • Public tier: 10 requests/min per IP.
  • If you need more, upgrade — see pricing.
  • 429 responses include a Retry-After header. Cache responses at least 60 s where reasonable.

Versioning

  • Breaking field renames will bump version inside /feeds/subnets.json and /feeds/meta.json.
  • Deprecated fields stay for at least 90 days before removal.
  • Check /feeds/meta.json in production on startup.
